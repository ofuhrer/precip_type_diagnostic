## One-month acceptance

January 2005 used a one-period analysis manifest with 744 expected messages.
The first candidate task, Slurm `5043004`, stopped before publication at a
spatially constant no-precipitation field. The test demonstrated that ecCodes
canonically encodes constant simple-packed fields with `bitsPerValue=0` and
that changing only this metadata to four corrupts decoded values. The contract
was corrected to require four bits for non-constant fields and zero bits only
for a decoded constant field.

The corrected task `5043008` and reducer `5043009` passed. A reporting-only
subset provenance bug was then corrected so source-generation quality counters
use only selected source receipts. Reducer `5043014` and deliberate independent
verification `5043015` passed at the accepted revision.

## Physical plausibility and limitations

The full-period point-hour shares are 86.7601% no precipitation, 10.2576% rain,
2.0892% snow, 0.3412% graupel, 0.3000% wet snow, and 0.1626% mixed rain/snow.
Freezing rain (code 3) is 0.039666%; freezing rain on ground (code 13) is
0.000140%. Complete-year combined freezing-rain frequency ranges from 0.01366%
in 2007 to 0.08638% in 2010. These are physically plausible descriptive
frequencies, not a trend attribution result.

Hail is absent, as expected because archived REA inputs do not contain the hail
rate used by the online ICON diagnostic. The source also lacks convective rates.
Archived packing noise caused negative adjacent accumulation differences; the
source workflow clamped and recorded them under its established contract.

The event catalogue contains 7,572 domain-wide temporal screening events.
Freezing rain occurs somewhere in the domain during 57,891 hours, but the
median positive footprint is only 30 grid cells. Events therefore are not
spatially coherent storm objects. The source has no reviewed cell-area field,
so extent is reported as grid cells, cell-hours, and domain fraction rather
than square kilometres.

## Decision

The compact GRIB, hourly Parquet, gridded frequency fields, screening event
catalogue, and plot-ready freezing-rain map satisfy the v0.5.0 analysis
contract. Retain the original 409 GB archive until downstream users accept the
compact product and its receipts.
